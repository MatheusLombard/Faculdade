Transação  tem inicio e fim 
É finalizado quando sucesso com o commit
e em caso de erro é mostrado um rollback

Rollback é geralmente realiizado automaticamente pelo sgbd

As trasações são organizadas em fila pelo próprio SGBD


O que é? 
 - Unidade logica de trabalho que dever ser concluida ou abortada inteiramente
 - Uma transação bem-sucedida altera o Bd de um estado consistente para outro
 - Um BD em um estado consistente é aquele em que são satisfeitas as restrições de integridade de todos os dados
 - A maioria reais 

ACID - ATOMICIDADE - OU É REALIZADA NA TOTALIDADE OU NÃO É REALIZADA, NÃO TEM PARCIAL, CONSTITUI UMA UNICA UNIDADE(TUDO OU NADA)
       CONSCISTENCIA - ESTADO CONSISTENTE PARA ESTADO CONSISTENTE
       ISOLAMENTO - TRANSAÇÕES SEPARADAS NÃO DEVEM INTERFERIR UMA COM A OUTRA
       DURAVEL - UMA VEZ QUE A TRANSAÇÃO SOFREU COMMIT, AS ALTERAÇÕES FEITAS AS BD SÃO PRESERVADAS, MESMO QUE A MÁQUINA EM QUE O SGBD ESTEJA INSTALADO APRESENTE FALHA POSTERIOMENTE

SAVE POINT, FAZ COM QUER EU FRAGMENTE MINHA TRANSAÇÃO, NÃO PRECSNADO, NO ROLLBACK, VOLTAR PARA O INICIO

CONTROLE DE CONCORRENCIA
 - A COORDENAÇÃO DE EXECUÇÃO SIMULTANEA DE TRASAÇÃO EM UM SISTEMA DE BD MULTIUSUAIROO
 - O OBJETIVO É GARANTIR A SERIALIZAÇÃO DAS TRASAÇÕES NESSE TIPO DE AMBIENTE - SERIALIZAÇÃO -> É FEITA EM SERIE 

'N BB



PROBLEMA DAS ATUALIZAÇÕES PERDIDAS: 


DADOS NÃO CONSOLIDADOS -> FEMOMENO ONDE OS DADOS NAÃO SÃO SALVOS/CONSOLIDADOS
 - ACONTECE QUANDO DUAS TRANSAÇÕES SÃO EXECUTADAS DE MODO CONCORRENTE
 - A PRIMEIRA É DESFEITA APÓS A SEGUNDA TER ACESSADO OS DADOS NÃO CONSOLIDADOS

RECUPERAÇÕES INCONSISTENTES

BANCO POSSUI UM AGENTE CHAMADO ESCALONADOR - > ORQUESTRA AS TRANSAÇÕES
	
NIVEIS DE ISOLAMENTO
 - LEITURA SUJA - > OCORRE QUANDO UAMÇA TRANSAÇÃO LÊ DADOS QUE AINDA NÃO FORAM CONFIRMADOS
 - LEITURA NÃO REPETIVEL -> OCORRE QUANDO UMA TRASAÇÃO LÊ A MESMA LINHA DUAS VEZES MAS OBTÉM DADOS DIFERENTES A CADA VEZ
 - LEITURA FANSTASMA -> UM FANTASMA É UMA LINHA QUE CORRESPONSDE AOS CRITÉRIOS DE PESQUISA MAS NÃO É VISTA INICIALMENTE


QUANTO MAIOR A PERFORMACE MENOR A CONSISTENCIA
QUANTO MENOS A PERFORMACE MAIOR A CONSISTENCIA
